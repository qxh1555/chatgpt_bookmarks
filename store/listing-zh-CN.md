# Chrome 应用商店上架文案

名称：对话书签 · ChatGPT

简短介绍：在 ChatGPT 长回答中标记阅读位置，随时一键返回。书签仅保存在本机。

语言：简体中文（zh-CN）

建议分类：工具 / 工作效率（以后台实际可选分类为准）

## 详细介绍

回答很长，读到一半又提出了新问题，回头却找不到刚刚读到的位置？

对话书签可以在 ChatGPT 对话中的具体文字位置留下书签。继续提问之后，点击书签就能跳回原文，接着读。

主要功能：
• 选中一段文字，点击「添加书签」。
• 未选中文字时，一键标记当前阅读位置。
• 点击列表中的书签，跳回原文并短暂高亮。
• 每段对话分别保存书签，可重命名和删除。
• 刷新或关闭页面后，书签仍保存在当前浏览器。
• 使用 Alt + Shift + B 快速添加书签。

使用方法：
1. 安装后刷新 ChatGPT 页面，并打开一段已保存的对话。
2. 选中回答中的一句话，点击出现的「添加书签」。
3. 点击右下方「书签」，选择一个书签即可返回。

隐私与权限：
书签、原文短片段及定位信息仅在本机处理和保存，不上传给开发者或第三方，不用于广告。扩展只在 chatgpt.com 和 chat.openai.com 网页运行，仅使用 storage 权限保存书签。无需额外注册或 API Key。

使用限制：
• 书签不会跨设备同步，卸载扩展会清除其本地数据。
• 临时对话和尚未保存的新聊天不支持持久书签。
• 较早的消息需要先在网页中加载。
• 原文被修改、删除或切换回答分支后，可能无法定位；扩展会显示提示。
• ChatGPT 网页结构变化时可能需要适配。

这是为 ChatGPT 网页提供书签功能的第三方扩展；产品名称中的 ChatGPT 用于说明适用网站。

## 单一用途

让用户在 ChatGPT 对话中的具体文字位置保存本地书签，并通过书签列表返回该位置。

## storage 权限说明

使用 chrome.storage.local 保存用户主动创建的书签名称、原文短片段、前后文、消息与对话标识、文字偏移和创建时间，以便刷新或重启浏览器后恢复书签，并同步同一浏览器配置中的标签页更新。数据不上传、不跨设备同步。

## 网站访问说明

内容脚本仅匹配 https://chatgpt.com/* 和 https://chat.openai.com/*。用于显示书签面板和选区按钮、在本机读取对话文字以生成和恢复定位锚点，并滚动到用户选择的书签位置。不读取其他网站或通用浏览历史。

## 远程代码说明

不使用远程托管代码。全部 JavaScript、样式、图标和本地隐私政策随扩展打包；无 eval、远程脚本、动态远程模块或分析服务。

## 数据处理填报依据

必须披露本机读取和存储的网页内容及个人通信片段。不要笼统填写「不处理任何用户数据」。只处理完成书签功能所需的数据，不传输、不出售、不用于广告、不用于信用或贷款评估。根据后台当前字段及说明逐项填写；如字段将「收集」限定为离开设备的传输，应按该定义回答，并在隐私政策中继续披露本地处理。不要把“不主动提取身份信息”写成“书签中绝不会包含个人信息”。
